**You can build and sell commercial products using Lloyal.**

New runtime versions use **FSL-1.1-MIT**, together with the
[Developer Grant](https://github.com/lloyal-ai/hdk/blob/d9112692d592f73e3922d096a4cdf2edcc889089/GRANT.md). Each version carrying this license becomes available under MIT
two years after it is first made available.

The grant expressly permits building, distributing, selling, licensing and
hosting applications and abilities, including products that compete with
Lloyal's own applications. Your application's own plugin system and private
ability distribution within your organization or to your customers are permitted.

During a version's FSL period, the grant limits competing-use restrictions to
substitute developer frameworks or runtimes, runtime-as-a-service for third-party
developers, and general alternative ability registries for third-party harness
developers. Hosting your own product for its end users is permitted.

Earlier versions carrying **FSL-1.1-Apache-2.0** retain their original terms,
irrevocable future Apache 2.0 rights, conversion dates and grant permissions.
The license shipped with a version determines its future license.

| Component | License |
|---|---|
| `liblloyal`, `@lloyal-labs/lloyal.node` | FSL-1.1-MIT + Developer Grant |
| `@lloyal-labs/sdk`, `@lloyal-labs/lloyal-agents`, `@lloyal-labs/rig` | FSL-1.1-MIT + Developer Grant |
| `@lloyal-labs/binding`, `@lloyal-labs/host`, `@lloyal-labs/relay`, `@lloyal-labs/desktop`, `@lloyal-labs/ui`, `@lloyal-labs/dev-tools` | FSL-1.1-MIT + Developer Grant |
| `@lloyal-labs/media`, `@lloyal-labs/web-ability`, `@lloyal-labs/corpus-ability`, `@lloyal-labs/documents-ability`, `@lloyal-labs/wikipedia-ability` | FSL-1.1-MIT + Developer Grant |
| `lloyal-ai` CLI, Fieldnote application source | MIT |
| `@lloyal-labs/channel-verify` | Apache 2.0 |
| `llama.cpp` (vendored dependency) | MIT |

Previously covered package names remain covered under Section 1 of the grant.
The canonical FAQ source is `licensing/faq.md` in this repository. HDK's
`scripts/sync-license-faq.sh` synchronizes it into `LICENSE-FAQ.md` copies and
copies the canonical HDK `GRANT.md` into the applicable runtime repositories
and packages. The root HDK `LICENSE` is the canonical runtime license.
Edit the canonical sources and run the sync script instead of editing
generated copies. See HDK's `scripts/LICENSING.md` for the full workflow.
